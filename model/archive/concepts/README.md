# concepts

Architecture notes about integrations planned for later stages of the project.

## Files

- `amuse.txt`
  - describes how AMUSE could tie together several solvers (N-body, hydro, stellar evolution)
  - focuses on a possible "project 2.0" version
- `atm.txt`
  - describes how ATM could supply asteroid temperature models
  - places ATM in the chain: orbit → temperature → chemistry / erosion

## Relation to the active code

These files are not part of the executable pipeline. They document decisions and
directions of development.
