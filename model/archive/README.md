# archive

Material that is technically inactive but still relevant to the project roadmap.

## Role of this directory

- separates planning notes from executable code
- collects ideas that have not been implemented yet
- keeps conceptual artifacts from mixing with the active pipeline

## Contents

| Path | Contents |
|---|---|
| `concepts/amuse.txt` | Analysis of a possible AMUSE integration as a multi-solver layer |
| `concepts/atm.txt` | Analysis of a possible ATM integration for asteroid thermal models |
| `concepts/README.md` | Short index of the concept notes |
| `legacy/` | Compatibility aliases for older import paths |
| `legacy_modules/` | Historical and experimental modules, plus the first-generation alias layout |

## Usage status

- nothing here is imported by the Python runtime
- `environment.ipynb` does not read these as input data
- these are reference and architecture materials only
