# Pinned dependencies for the model and its test suite.
#
# requirements.txt lists what the whole project can use, unpinned, including the
# analysis notebooks. This file is the smaller set the physics actually needs,
# with exact versions.
#
# Pinning matters here more than in most projects. The provenance block claims
# that a run reproduces bit for bit from its digest, and it records the package
# versions to make that checkable — but recording a version is only half of the
# guarantee. Without pins, two people following the same instructions install
# different builds of numpy and get different floating-point results from the
# same seed, and the digest says they should have matched.
#
# Versions are the ones this project is developed and tested against. Raise them
# deliberately, and rerun the suite when you do: the tests anchor several
# physical constants to published values, so a numerical change that shifts a
# result will be caught rather than absorbed.
#
# Install:  pip install -r requirements-ci.txt
