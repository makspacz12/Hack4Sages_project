# aliases_v1

Copies of the former alias modules from the root of `microbe_radiation_model/`, which
were removed when the package structure was flattened into layers.

## Purpose

- preserve a historical reference of the alias implementations
- allow comparison between the previous and the current package organisation
- support manual migration of old imports if needed

## Status

- these files are not part of the active runtime
- they are not a supported API
- new code must not import them
